| C4 コンテンツ品質 | ✅ 旬ピークの母数下限＋定義併記＋海況実勢を追加（不変条件 #57） |

- 一次体験は `normalize/field_reports.json`（書き方は `normalize/FIELD_REPORTS_GUIDE.md`）
- 体感をサイトの実データで裏取りできたものが10件（イサキの夏偏り・タチウオのテンヤ大型・
  イカ3種の混じり方・サバの外道率・アマダイの外道同定=ムシガレイ・出世魚の段階 等）。
  **この「体感→データ照合」の組み合わせが、自動収集にも体験ブログにも単独では書けない独自性**
- 港・船宿は「事実（駐車場・受付時間＝記憶で書かない）／体験（その日どうだったか＝書ける）」
  で分離するルールをガイドに明記。公式サイト391件の自動クロールは抽出精度が出ないため不採用
